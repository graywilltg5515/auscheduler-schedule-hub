## Project Overview

AUScheduler provides a browser-accessible workspace for organizing university schedules, with its primary use case centered on Aerospace University. The HTML-based application brings academic planning and schedule information together through a simple web interface.

It is intended for departments and teams that want an uncomplicated way to coordinate academic scheduling. By keeping the tool lightweight and browser-based, schedule details can be accessed, reviewed, and maintained without a complex application environment.

## Working with the Application

Start by opening the application in a modern web browser. The main page serves as the workspace for academic schedule planning and related updates.

A standard use cycle is:

1. Open the main HTML page.
2. Inspect existing scheduling details or make updates.
3. Add or manage academic planning entries.
4. Save or publish the resulting changes based on your hosting configuration.

When developing locally, a basic static server can provide a convenient preview while HTML files are being modified.
